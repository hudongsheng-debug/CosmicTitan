# 宇宙泰坦支持 / Cosmic Titan Support

联系 / Contact：hudongsheng356@gmail.com
适用系统 / Requirements：macOS 14 或更高版本 / macOS 14 or later.

打开与保存：⌘O 打开 .titan 工程，⌘S 保存。保存时选择自己有写入权限的目录。
Open and save: Command-O opens .titan projects; Command-S saves them to a location you select.

语言：工具栏“更多”→ Language / 语言。支持简体中文与英文；用户内容保留原文。
Language: Toolbar More menu > Language / 语言. Simplified Chinese and English are available; user content retains its original language.

分析结果：先检查模型适用范围、单位和参数。输入改变后请重新计算。NaN 或质量标记不能解释成零信号。
Results: Check model scope, units and inputs. Recalculate after edits. NaN or quality flags do not represent zero signal.

反馈请提供版本号、macOS 版本、操作步骤与错误信息。可附不含敏感内容的最小复现工程；请勿发送账号密码。
When reporting an issue, include the app version, macOS version, steps and error message. An optional minimal non-sensitive project helps reproduce the issue. Never send passwords.
